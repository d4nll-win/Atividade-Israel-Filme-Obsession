# Atividade-Israel-Filme-Obsession

Projeto desenvolvido em HTML com o objetivo de apresentar informações sobre o filme **Obsession**, escrito e dirigido por **Curry Barker**.

## Sobre o projeto

O site apresenta informações sobre a história, personagens, elenco, trilha sonora, curiosidades, produção e bastidores de **Obsession**.

Também foram adicionadas páginas interativas utilizando recursos do HTML, como formulários de feedback, avaliação do filme e um quiz sobre a obra.

O projeto foi desenvolvido utilizando apenas **HTML**, sem CSS ou JavaScript, com foco na utilização de elementos semânticos, formulários, recursos multimídia e outros recursos do HTML5.

## Páginas

- **Home** — Apresentação do filme, informações sobre Curry Barker, trailer e imagens.
- **História** — Apresentação da história e dos principais acontecimentos de Obsession.
- **Elenco** — Informações sobre os principais personagens e atores.
- **Trilha Sonora** — Informações sobre a trilha sonora e suas faixas.
- **Curiosidades** — Curiosidades sobre o filme, elenco, produção e trilha sonora.
- **Produção** — Informações sobre a produção e realização do filme.
- **Galeria** — Imagens relacionadas ao filme, personagens e bastidores.
- **Bastidores** — Informações sobre as filmagens, erros de gravação, refilmagens e momentos dos bastidores.
- **Feedback** — Formulário para que os visitantes possam enviar opiniões sobre o site.
- **Avaliação** — Página para avaliar o filme utilizando uma escala de até cinco estrelas.
- **Quiz** — Quiz com 10 perguntas sobre Obsession e gabarito no final.

## Avaliação

A página de avaliação permite que o visitante atribua uma nota de até cinco estrelas ao filme.

Também existe um campo para que o visitante possa explicar o motivo da nota escolhida.

## Feedback

A página de feedback possui um formulário com diferentes tipos de campos para que o visitante possa compartilhar sua opinião sobre o site.

Entre os recursos utilizados estão:

* Nome
* E-mail
* Data
* Radio buttons
* Checkboxes
* Escala de avaliação
* Seleção de cor
* Datalist
* Campo de texto
* Upload de arquivo

## Observação sobre os formulários

Como o projeto foi desenvolvido somente com HTML, os formulários não possuem um sistema de backend para armazenar ou processar as respostas.

Os formulários servem principalmente para demonstrar a utilização dos recursos de formulários disponíveis no HTML5.
